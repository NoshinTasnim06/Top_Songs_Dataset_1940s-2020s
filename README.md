# 🎵 Top Songs Dataset: Billboard Hot 100 × Music Classics (1940s–2020s)

A data cleaning and merging project that combines Billboard Hot 100 chart history with song-level audio features to create a single curated dataset of **top songs spanning eight decades**. The result balances **commercial success** (chart performance) with **musical characteristics** (energy, danceability, loudness, and more), ready for analysis, visualization, or machine learning.

---

## Project Goals

- Import and inspect two independent music datasets.
- Isolate each song's strongest Billboard performance.
- Merge chart data with audio-feature metadata.
- Clean, standardize, and export a tidy analysis-ready dataset.

### Questions this dataset can help answer

- How have popular genres evolved over time?
- Which audio features (energy, danceability, loudness, etc.) are most associated with chart success?
- Which decades had the most musical variety?

## Data Sources

| Dataset | File | Size | Description |
|---|---|---|---|
| **Billboard Hot 100** | `hot-100-current.csv.zip` | 343,600 weekly chart entries | Weekly chart records: chart week, title, performer, current/last week rank, peak position, weeks on chart |
| **Music Classics** | `ClassicHit.csv` | 15,150 tracks | Track metadata and audio features: genre, year, duration, popularity, energy, danceability, loudness, and more |

> **Note:** The raw CSV files are not included in this repository. See [Reproducing the Results](#reproducing-the-results) to use your own copies.

## Methodology

1. **Explore both datasets.** Check structure, data types, and missing values. The only gaps found were in Billboard's `last_week` column (new entries have no prior-week rank).
2. **Select each song's best chart record.** Group Billboard entries by `title` + `performer` and keep the row with the most weeks on chart, so every song appears once.
3. **Merge on song identity.** Inner join Billboard and Classics on title/track and performer/artist, keeping only songs present in both datasets.
4. **Validate.** Confirm there are no duplicate rows after merging.
5. **Clean and standardize.** Normalize column names to lowercase snake_case, drop columns not needed for the analysis, and reorder the remaining ones.
6. **Export** the final dataset to CSV.

## Output

**File:** `Top_Songs_Dataset(1940s-2020s).csv`
**Shape:** 3,454 songs × 13 columns

| Column | Description |
|---|---|
| `year` | Release year |
| `title` | Song title |
| `artist` | Performing artist |
| `genre` | Genre label from the Classics dataset |
| `peak_pos` | Highest position reached on the Hot 100 |
| `wks_on_chart` | Weeks spent on the Hot 100 |
| `duration` | Track length (milliseconds) |
| `popularity` | Popularity score |
| `energy` | Intensity and activity level (0–1) |
| `danceability` | Suitability for dancing (0–1) |
| `loudness` | Overall loudness (dB) |
| `speechiness` | Presence of spoken words (0–1) |
| `liveness` | Likelihood the track was recorded live (0–1) |

## Limitations

- **Exact-match merge.** Songs whose titles or artist names are formatted differently across the two datasets (e.g., featured artists, punctuation) are not matched, so the final set is a subset of both sources.
- **Genre labels.** Genre values come from the Classics dataset as-is. Some recent tracks carry a generic label such as "Today" rather than a true genre, which should be recoded before genre-based analysis.
- **Selection bias.** Only songs present in both datasets are included, so the result represents a curated sample rather than the full Hot 100 history.

## Reproducing the Results

1. **Install dependencies**
   ```bash
   pip install pandas jupyter
   ```
2. **Add the source data.** Place `hot-100-current.csv.zip` and `ClassicHit.csv` in a local folder.
3. **Update the file paths** in the "Load the datasets" cell of `data.ipynb` to point to your copies.
4. **Run the notebook** top to bottom:
   ```bash
   jupyter notebook data.ipynb
   ```
5. The cleaned dataset will be saved as `Top_Songs_Dataset(1940s-2020s).csv` in the notebook's working directory.
